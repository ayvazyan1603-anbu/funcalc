# FunPay Калькулятор Наценки и Вывода (Android & Web)

Современное мобильное приложение для расчёта розничной наценки лотов FunPay, детализации всех удержаний криптовалютных переводов (USDT TRC20, TON CryptoBot, P2P) и прогнозирования чистой суммы «на руки».

---

## 📱 Особенности интерфейса (Mobile First, Dark Theme)

1. **Вкладка 1: «Цена товара»**
   - **Закреплённая плашка сверху:**
     - Крупная цена продажи в ₽ (точная и округлённая по психологическому правилу до окончания на `9`, например `148 ₽` → `149 ₽`) и в $ (`$1.78`).
     - Кнопка **«Скопировать ₽»** с виброоткликом (`navigator.vibrate`) и всплывающим уведомлением (Toast).
     - Строка наценки и чистой прибыли с 1 шт.
   - **Ввод параметров:**
     - Закупочная цена (USDT) с цифровой клавиатурой.
     - Синхронизированный курс USDT/RUB (₽) с кнопкой сброса.
     - Быстрые чипы ROI (`x1.5`, `x2.0 (активен)`, `x2.5`, `x3.0`, а также произвольное значение).
   - **Сворачиваемый блок настроек:**
     - Ползунок и ввод объёма партии закупа/вывода (USDT) с автобейджем тарифа (@BitcoinOperator: `Вход: +4.4% / Выход: -2.4%`).
     - Переключатель маршрута:
       1. `USDT → TON (CryptoBot) → Обменник` (своп `0.75%` + тариф обналичивания).
       2. `Напрямую USDT → Обменник` (без свопа, только тариф обменника).
       3. `P2P-маркет CryptoBot` (фиксированно `1.0%`).
     - Тонкая настройка комиссий (комиссия продажи FunPay `6%`, вывода `2%`, фикс `$1.50`, фикс закупа `$1.00`).
   - **Детализация потерь на 1 шт.:** пошаговый водопад от цены закупа у поставщика до чистых денег на руках.

2. **Вкладка 2: «Вывод средств»**
   - **Закреплённая плашка сверху:**
     - Сумма на карту/счёт: `XXXX ₽` и `$XX.XX`.
     - Всего удержано комиссий: `-XXX ₽ (-$X.XX | X.X%)`.
     - Предупреждение о сумме `< $20` (доп. комиссия обменника 200 AMD на микро-сделки).
   - **Ввод суммы к выводу:**
     - Переключатель валюты `₽` / `$`.
     - Быстрые чипы популярных сумм (`3 000 ₽`, `5 000 ₽`, `10 000 ₽`, `25 000 ₽` или `$50`, `$100`, `$200`, `$500`).
   - **Водопад удержаний:** от баланса FunPay до поступления на карту.

3. **Вкладка 3: «Прайс-лист»**
   - Каталог товаров с поиском.
   - Автоматический пересчёт продажных цен и прибыли всех позиций в реальном времени по актуальному курсу и множителю.
   - Добавление, удаление и быстрое копирование цен.

4. **Локальное сохранение (`localStorage`):**
   - Все поля, введённые значения, открытые аккордеоны и каталог сохраняются локально.

## 🛠 Математические формулы и тарифная сетка

### Тарифы обменника (@BitcoinOperator):
- **Покупка USDT ($k_{\text{buy}}$):**
  - $0 < S \le 50$: $+5.9\%$
  - $50 < S \le 100$: $+4.4\%$
  - $100 < S \le 200$: $+3.4\%$
  - $200 < S \le 400$: $+2.9\%$
  - $400 < S \le 500$: $+2.4\%$
  - $500 < S \le 1000$: $+1.9\%$
  - $1000 < S \le 3000$: $+0.9\%$
  - $S > 3000$: $0.0\%$
- **Обналичивание ($k_{\text{out}}$):**
  - $0 < S \le 100$: $-3.2\%$
  - $100 < S \le 500$: $-2.4\%$
  - $500 < S \le 1000$: $-1.9\%$
  - $S > 1000$: $-1.8\%$

### Расчёт цены продажи:
1. $N = B / P$
2. $C_{\text{total}} = B \times (1 + k_{\text{buy}}) + F_{\text{buy}}$
3. $\text{Target}_{\text{net}} = C_{\text{total}} \times K$
4. $\text{After}_{\text{fp\_out}} = \frac{\text{Target}_{\text{net}}}{(1 - k_{\text{swap}}) \times (1 - k_{\text{out}})}$
5. $\text{After}_{\text{fp\_sale}} = \frac{\text{After}_{\text{fp\_out}} + F_{\text{fp\_out}}}{1 - k_{\text{fp\_out}}}$
6. $\text{FP}_{\text{gross}} = \frac{\text{After}_{\text{fp\_sale}}}{1 - k_{\text{fp\_sale}}}$
7. $\text{Price}_{\text{USD}} = \text{FP}_{\text{gross}} / N, \quad \text{Price}_{\text{RUB}} = \text{Price}_{\text{USD}} \times \text{Курс}_{\text{RUB}}$

## 📦 Сборка APK-файла

### Способ 1: Автоматическая облачная сборка через GitHub Actions (рекомендуется)
В репозитории настроен рабочий процесс `.github/workflows/build-apk.yml`.
1. Загрузите код в ваш репозиторий GitHub:
   ```bash
   git init
   git add .
   git commit -m "FunPay Calculator Initial Commit"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/funpay-calculator.git
   git push -u origin main
   ```
2. Откройте вкладку **Actions** в репозитории на GitHub.
3. Через ~2 минуты завершится сборка задачи **Build Android APK**.
4. В разделе **Artifacts** нажмите на **FunPay-Calculator-Android-APK** и скачайте готовый `FunPay-Calculator-v1.0.apk` прямо на смартфон!

### Способ 2: Локальная сборка в Android Studio
1. Откройте папку `android` проекта в **Android Studio**.
2. Дождитесь синхронизации Gradle.
3. Нажмите **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. Готовый файл появится в `android/app/build/outputs/apk/debug/app-debug.apk`.

### Способ 3: Мгновенный запуск на телефоне через Wi-Fi
1. Запустите двойным кликом файл `preview.bat` (или команду `python run_preview.py`).
2. В консоли отобразится локальный адрес (например, `http://192.168.1.100:8080`).
3. Откройте этот адрес в Chrome на смартфоне и нажмите **«Добавить на главный экран»** — приложение установится как нативное PWA с полноэкранным режимом и виброоткликом!
